# REST + SSE API Contract

Base URL: `http://127.0.0.1:8765/api`. JSON bodies; errors are `{"detail": "..."}` with 4xx/5xx.
The OpenAPI schema is generated by FastAPI at `/api/openapi.json` and is the authoritative typed
contract; this document fixes the endpoint surface.

| Method | Path | Purpose | FR |
|--------|------|---------|----|
| GET | `/health` | liveness + version | — |
| GET | `/config` | non-secret defaults: `RunConfig` defaults, configured deployments, which credentials are present (booleans only) | FR-004 |
| POST | `/connections/verify` | body `{checks?: ["aoc","workhorse","escalation","sandbox"]}` → per-check `{name, status: pass\|fail\|skipped, detail, latency_ms}`; never submits | FR-005, FR-046 |
| GET | `/runs` | list runs (summary) | FR-025 |
| POST | `/runs` | create run: `{calendar_url?, year?, day_from, day_to, auto_submit, authorize_submission: bool, config?: Partial<RunConfig>}`; `auto_submit=true` requires `authorize_submission=true` (else 422); validates session for live runs | FR-001–FR-005 |
| GET | `/runs/{id}` | run detail incl. totals and config | FR-032 |
| POST | `/runs/{id}/start` · `/pause` · `/resume` · `/stop` | control; 409 on invalid transition | FR-025 |
| POST | `/runs/{id}/parts/{day}/{part}/retry` | retry FAILED/BLOCKED part (resets attempt counters for that part only; ledger kept) | FR-025 |
| POST | `/runs/{id}/parts/{day}/{part}/approve` | manual-approval mode: approve the pending candidate | FR-003 |
| GET | `/runs/{id}/progress` | 25-day calendar: per part derived UI state + stars | FR-033 |
| GET | `/runs/{id}/parts/{day}/{part}` | part detail: understanding, attempts, examples meta, submissions | FR-032 |
| GET | `/runs/{id}/parts/{day}/{part}/revisions` | code revisions with execution results | FR-034 |
| GET | `/runs/{id}/submissions` | submission history | FR-017 |
| GET | `/runs/{id}/metrics` | tokens, calls, latency, cost per model and per part, escalations | FR-037 |
| GET | `/runs/{id}/events?after_id=` | paginated event history | FR-031 |
| GET | `/runs/{id}/events/stream` | SSE; honors `Last-Event-ID` header or `?after_id=`; event `id` = Event.id, `event` = `message`, `data` = Event JSON (type in `data.type`); keep-alive every 15 s | FR-031 |
| POST | `/runs/{id}/replay` | `{speed: number (1–100)}` → creates replay run (mode=replay) and starts streaming recorded events; no external calls | FR-039 |
| DELETE | `/runs/{id}` | delete local run data; response includes `notice: "Advent of Code account progress is not affected"` | FR-028 |
| POST | `/local-data/reset` | reset all local runs (cache kept unless `include_cache`); same notice | FR-028 |

`RunConfig` (all optional on create; defaults from settings):
`max_attempts_per_part=6, escalate_after_failures=3, escalate_on_timeout=true,
max_submissions_per_part=3, exec_timeout_s=30, exec_timeout_max_s=120, max_spend_usd=20,
aoc_min_interval_s=5, workhorse_efforts=["medium","medium","high"], escalation_effort="high"`.
